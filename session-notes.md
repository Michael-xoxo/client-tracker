## Task 2.1 - User Entity, Password Hashing & JWT Authentication Guard (2026-11-02)
- **Architectural Decision**: Used an async Mongoose `pre('save')` middleware hook without the legacy `next` callback parameter to align with Mongoose 9's promise-based middleware architecture, ensuring passwords are only hashed when modified (`this.isModified('password')`) and never returned in JSON payloads or `req.user` queries (`select('-password')`).
- **Friction Point / Bug Encountered**: During adversarial verification via `curl.exe` in Windows PowerShell, inline double quotes in `-d` arguments were stripped by PowerShell's native command argument parser, causing `body-parser` JSON `SyntaxError`s and connection race conditions before MongoDB finished connecting. Resolved by polling port 5000 readiness with `Test-NetConnection` and piping the JSON payload via stdin (`-d "@-"`) to `curl.exe`.
